# Corpus Library

Corpus Library is a catalog of searchable datasets and document collections
for you and your coding agent. Find sources relevant to your work, add a
collection to Corpus, and search it locally.

Each collection is published as a corpus: a searchable snapshot with an
`org/name` reference. Its README explains what it covers, the questions it can
help answer, and how to interpret its search results.

## Open Source

This repository contains the importers, corpus definitions, and documentation
used to prepare Library collections. Explore how each collection is assembled,
report issues, or contribute improvements to source coverage, data quality,
and documentation.
